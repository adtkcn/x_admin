### 接口路径说明

所有接口`api/`开头,方便反向代理

后台接口`api/admin`开头，后台权限及菜单设计以这个为主

前台(C端)接口`api/web`开头

设备接入接口`api/iot`开头（HTTP 上报/心跳，走设备凭证鉴权，与后台登录态无关；`IOT.Enable=false` 时不注册）
