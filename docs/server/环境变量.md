# 环境变量

后端使用 Viper 读取配置文件 `config/init.go` 完成配置加载与合并。

## 配置文件名

- 默认读取运行目录下的 `.env.yaml`；
- 可通过命令行参数指定：`-env=.env.yaml`；
- 仓库内提供模板 `.env.yaml.example`，线上可另用 `.env.online.yaml`。

## 加载规则

- 有 `mapstructure` tag 的字段，名称以 `mapstructure` 为准，尽量使用大驼峰命名。
- 支持嵌套结构（如 `DB`、`REDIS`、`Email` 为数组）与多账号配置。

## 核心配置段

| 配置段 | 说明 |
| --- | --- |
| `APP` | 应用端口、运行模式、名称 |
| `DB` | 数据库连接（host/port/user/pwd/name） |
| `REDIS` | Redis 地址与密码（队列/锁/缓存依赖） |
| `FILE` | 文件上传大小限制、分片、预签名等 |
| `Email` | 邮件账号（**数组**，多账号随机发送） |
| `GeTui` | 个推推送配置 |
| `JWT` / `AdminJWT` | C 端 / 后台 JWT 密钥与过期时间 |
| `Wechat` | 微信小程序 / 公众号 AppID+Secret |
| `Log` | 日志级别与输出 | 

## 配置结构源码

参考 `config/init.go` 中的 `config` 结构体（含 `APP/DB/REDIS/FILE/GeTui/Email/Log/JWT/AdminJWT/Wechat/` 各段）。

```go
// config/init.go
type config struct {
    APP    *AppConfigStruct
    DB     *DBConfigStruct
    REDIS  *RedisConfigStruct
    FILE   *FileConfigStruct
    GeTui  *GeTuiConfigStruct
    Email  *[]EmailConfigStruct
    Log    *LogConfigStruct
    JWT    *JwtConfig
    AdminJWT *JwtConfig
    Wechat *wechatConfig
}
```
