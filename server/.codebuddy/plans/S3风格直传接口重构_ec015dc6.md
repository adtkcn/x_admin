# S3 风格直传接口重构

## 设计思路

- **不需要 minio-go**：预签名 URL 采用 HMAC-SHA256 签名机制（标准库 `crypto/hmac`），无需任何第三方 SDK
- **S3 风格接口**：接口命名和语义对齐 S3（CreateMultipartUpload / UploadPart / CompleteMultipartUpload 等），方便前端使用 S3 SDK 对接
- **预签名 URL 直传**：后端签发带签名的临时 URL，前端直接上传文件到该 URL，减少后端文件流量
- **一键切换 S3**：存储逻辑通过 `StorageEngine` 接口抽象，切换时只需新增一个 S3 实现 + 修改工厂配置

## 接口设计

| 方法 | 路由 | 认证 | 说明 |
|------|------|------|------|
| GET | `/api/admin/s3/checkFileExist` | token | 秒传检查 |
| POST | `/api/admin/s3/createMultipartUpload` | token | 初始化分片上传 |
| POST | `/api/admin/s3/uploadPart` | token | 上传分片（经后端） |
| PUT | `/api/admin/s3/uploadPartDirect` | 预签名 | 直传分片（前端直传） |
| GET | `/api/admin/s3/listParts` | token | 列出已上传分片 |
| POST | `/api/admin/s3/completeMultipartUpload` | token | 完成合并 |
| POST | `/api/admin/s3/abortMultipartUpload` | token | 中止上传 |
| POST | `/api/admin/s3/putObject` | token | 小文件上传（非分片） |
| PUT | `/api/admin/s3/putObjectDirect` | 预签名 | 小文件直传 |
| POST | `/api/admin/s3/presign` | token | 生成预签名 URL |

## Task 1: 新增预签名工具 `plugin/presign.go`

HMAC-SHA256 签名/验签工具，用于生成和校验预签名 URL。

```go
// 签名载荷：{uploadId}|{fileKey}|{partNumber}|{expiresAt}
// 生成签名 URL: /api/admin/s3/putObjectDirect?sig=xxx&exp=xxx&key=xxx
func GeneratePresignedURL(action, fileKey string, expiresAt int64) (string, error)
func VerifyPresignedParams(sig, fileKey string, expiresAt int64) bool
```

使用 `config.FileConfig.PresignSecret` 作为密钥（若为空则用 `AdminConfig` 的 JWT secret 兜底）。

## Task 3: 新增控制器 `app/controller/admin_ctl/common_controller/s3_upload.go`

替换现有 `upload_chunk.go`，新增 `S3UploadHandler`，包含以下方法：

- `CheckFileExist` - 秒传检查（复用 FileHashService）
- `CreateMultipartUpload` - 初始化分片上传
- `UploadPart` - 上传分片（token 认证，文件经后端转发到 StorageEngine）
- `UploadPartDirect` - 预签名直传分片（签名验证后直接写入）
- `ListParts` - 列出已上传分片
- `CompleteMultipartUpload` - 合并分片并记录哈希
- `AbortMultipartUpload` - 中止上传清理临时文件
- `PutObject` - 小文件上传
- `PutObjectDirect` - 小文件预签名直传
- `Presign` - 生成预签名 URL（支持 putObject / uploadPart 两种 action）

保留 `checkFileExt` 和 `buildFileKey` 工具函数（从 `upload_chunk.go` 迁移）。

## Task 5: 新增路由 `routes/admin_route/s3_route.go`

```go
func initS3Route(rg *gin.RouterGroup) {
    h := common_controller.S3UploadHandler{}
    s3 := rg.Group("/s3")
    // token 认证组
    auth := s3.Group("", middleware.LoginAuth())
    auth.GET("/checkFileExist", h.CheckFileExist)
    auth.POST("/createMultipartUpload", h.CreateMultipartUpload)
    auth.POST("/uploadPart", middleware.RecordLog("S3上传分片"), h.UploadPart)
    auth.GET("/listParts", h.ListParts)
    auth.POST("/completeMultipartUpload", h.CompleteMultipartUpload)
    auth.POST("/abortMultipartUpload", h.AbortMultipartUpload)
    auth.POST("/putObject", middleware.RecordLog("S3上传文件"), h.PutObject)
    auth.POST("/presign", h.Presign)
    // 预签名认证组（无需 token，用签名验证）
    s3.PUT("/putObjectDirect", h.PutObjectDirect)
    s3.PUT("/uploadPartDirect", h.UploadPartDirect)
}
```

在 `init()` 中注册 `initS3Route`，移除 `initChunkRoute`。
